## What this is

The complete, locked blueprint for the company website. Every decision has been made and approved by the owner. The build chat and Claude Code follow this exactly.

**Nothing in these files changes without explicit approval from the owner.**

---

## How to use these files

**Starting the build chat:**
1. Owner opens a new chat and pastes all 14 files (or points the chat to this folder).
2. Owner's first message: *"This is the blueprint. Read every file in order. Confirm you understand the golden rules and phased workflow. Then propose Phase 1. Do not execute anything until I approve. Claude Code handles all file writes — you do not write to disk directly."*
3. Build chat proposes, owner approves, Claude Code executes.

**During the build:**
- Build chat re-reads relevant files before each phase.
- Claude Code updates `STATUS.md`, `DECISIONS.md`, `CHANGELOG.md` at the end of every phase.
- No phase starts before the previous is approved.
