# 01 — Project Overview, Stack, Hosting, Domain

---

## Project

- **Company:** Jackson & Grear Cornerstone Construction
- **Location:** Boise County, Idaho (rural)
- **Type:** Informational website, 5 pages
- **Owner:** Joseph Grear
- **Partner:** Jeremiah Jackson
- **Goal:** Modern-looking, mobile-friendly, easy to update, free to host

---

## Stack

- **Static HTML / CSS / JS only.**
- **No frameworks.** No React, no Vue, no Next.js, no Astro.
- **No build tools.** No npm, no Webpack, no Vite, no bundlers.
- **No CMS.** No WordPress, no Ghost, no Contentful.
- **No backend.** No database, no server-side code.

Rationale: informational site, owner wants easy updates, zero infrastructure to maintain.

---

## Hosting

- **GitHub Pages** (free tier).
- Auto-deploy on push to `main` branch.
- Owner is comfortable with GitHub.

---

## Domain

- **Launch:** Free `*.github.io` URL.
- **Later:** Owner buys `.com` variant of company name when funds allow.
- **Migration:** DNS repoint at the same GitHub repo. No rebuild, no code changes.
